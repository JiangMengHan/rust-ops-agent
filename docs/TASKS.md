# 开发任务明细与最终验收

更新日期：2026-10-21。架构与完整功能以 [架构设计](ARCHITECTURE.md) 为准，项目状态见 [README](../README.md)。

本清单按具体开发依赖编排，用于完成同一个最终产品。当前只有文档和目录骨架，下列实现、代码审查、部署与测试任务均未完成。文件夹存在、代码可编译或配置可填写，都不能单独作为功能通过的证据。

## 执行与记录规则

1. 按 T01 → T32 顺序推进；明确前置后可并行局部工作，但不能跳过集成门槛。每项开发都包含对应测试，最后再做整体独立审查与真实环境验收。
2. 完成任务后勾选标题，并在文末记录提交、实际执行命令、结果和证据位置；失败和未覆盖项如实保留。
3. 本机单元/模拟测试与真实部署验收分别记录，不能用 localhost、模拟节点或编造日志替代实际网络和系统兼容验证。
4. 真实账号、地址、用户/节点凭证和原始证据保存在被忽略的 `.local/` 或 `configs/local/`，公开只放占位样例与脱敏摘要。
5. CI 从工程建立时执行；每项通过相关检查后继续。最终测试后的修改必须回归并复审，不能沿用修改前的通过结果。

## 一、工程基础与可测试核心

### [ ] T01 建立 Cargo workspace、测试入口与 CI

- **前置：** 当前目录骨架与架构已保存。
- **实现：** 根 Cargo.toml、稳定工具链、Cargo.lock，四个业务 crate 的 Cargo.toml/src；把 `tests/integration` 建为显式 workspace member；创建真实 CI workflow。
- **交付：** 最小可构建入口、测试 harness、fmt/clippy/test 命令；源码替换对应 `.gitkeep`，不要伪造诊断能力。
- **验收：** 干净克隆可运行 `cargo fmt --check`、`cargo clippy --workspace --all-targets -- -D warnings` 和 `cargo test --workspace`；确认集成测试被发现。Linux CI 必须运行，办公端构建范围含 macOS。

### [ ] T02 明确环境、兼容矩阵与资源验收方法

- **前置：** T01。
- **实现：** 记录目标 CPU/内核/发行版/libc、systemd/journald、网络/代理、日志格式/权限、实际 MCP 客户端及节点规模；补充到架构对应表格。
- **交付：** 支持/未知/不支持组合，容量/时延/内存/CPU/IO 的测量方法与待确认预算，不把未知参数写成承诺。
- **验收：** 未知服务器参数不阻塞共享协议与本机开发；真实环境兼容和数值门槛必须在 T28 冻结，不能用默认配置冒充实测。

### [ ] T03 固定工具 schema、传输协议与生命周期

- **前置：** T01、T02。
- **实现：** ops-protocol 中定义节点/实例/会话/请求标识、版本与能力、工具输入输出、HTTP 接口、WS 消息和错误码。
- **交付：** request/accepted/chunk/terminal/cancel/hello/心跳；query_status 与 coverage.exhaustive 分离，定义序号、部分结果、未知、截止时间及用量单位。
- **验收：** 序列化往返、版本不兼容、非法预算、超限帧、重复终态、缺终态中断；更新架构中的正式接口与字段，不留互相矛盾的示例。

### [ ] T04 实现配置校验、凭证加载与诊断日志

- **前置：** T03。
- **实现：** 四个组件的类型化配置和无真实凭证的 `configs/examples`；默认无文件/日志访问，配置校验错误可定位；秘密从受限文件/系统凭证读取。
- **交付：** 配置校验入口、版本/修订、日志分级与敏感字段处理，MCP stdout 与 stderr 分离。
- **验收：** 缺字段/越界/冲突明确拒绝；token、正文和真实访问参数不出现在日志/错误/进程参数或公开样例。

### [ ] T05 实现预算、调度、取消和执行通道

- **前置：** T03、T04。
- **实现：** 准入先于建任务；有界队列/缓冲，长扫描与短读取调度，控制消息保留能力；单调计时与剩余预算传播。
- **交付：** 可复用预算/取消类型、每请求与跨请求配额、无进展处理和降级状态。
- **验收：** 分别触发条数/字节/时间/排队/并发上限；取消可观察、排队过期不执行；已开始阻塞 IO 的退出延迟单列，不声称 abort 可强停。

### [ ] T06 实现机器信息与按需主机采样

- **前置：** T02、T05。
- **实现：** ops-node 的 host.info/host.status，读取固定的 /proc、/sys 及系统元信息；CPU 型号/可见核数与动态使用率分开。
- **交付：** OS/内核/架构/启动、内存/swap/load、按需总体/分核 CPU 和可得压力字段，单位/来源/采样区间/可见范围。
- **验收：** 参考系统信息独立核对；两次采样正确，权限/字段缺失为 null 加原因；容器不冒充整机，空闲不周期采样。

### [ ] T07 实现安全文件解析与打开核心

- **前置：** T04、T05。
- **实现：** 节点目录别名/相对路径，基于目录 FD 的实际打开约束；openat2 与旧内核逐层不跟随链接路径。
- **交付：** 普通文件/允许文件系统校验、根目录修订、越界及链接拒绝、可复用 file_ref。
- **验收：** Linux 上验证路径穿越、前缀碰撞、路径替换竞态、软链接、权限不足及设备/FIFO/套接字；不靠先 canonicalize 后打开保证边界。

### [ ] T08 实现目录、属性、分段和尾部读取

- **前置：** T07。
- **实现：** files.list_roots/list/stat/read/tail/read_context 的本地核心，有界枚举/排序/分页和单次正文限制。
- **交付：** 文件身份、冻结范围、原始字节域、expected_file_ref/match_ref，追加/轮转/截断和编码异常结果。
- **验收：** 大文件内存不随文件总量增长；目录变动、超长行、无效 UTF-8、搜索后回读前替换、同名新文件均有准确行为。

## 二、连接与真实客户端闭环

### [ ] T09 实现网关 SQLite 与审计存储

- **前置：** T03、T04。
- **实现：** ops-gateway 的版本化迁移、节点/用户/授权/凭证校验/节点凭证元信息/安全修订与审计表组，WAL、有界数据库通道。
- **交付：** 原子管理事务、审计开始/结束/中断、数据库测试和一致性备份接口；不存任何凭证明文和日志正文。
- **验收：** 重启持久化、迁移失败恢复、并发注册、审计写失败/满盘行为；在线会话和短期游标不会从库自动恢复或重放。

### [ ] T10 实现用户授权与独立节点凭证

- **前置：** T04、T09。
- **实现：** 受本机权限保护的管理入口、节点预登记与有限期独立访问凭证，办公用户有限期令牌及基础授权；高熵凭证只持有原文，网关存校验材料。
- **交付：** 可操作的登记/发凭证/授予/撤销流程，凭证类型与 node_id 绑定，原文受限文件读取和事务边界；不实现 PKI/CSR/证书管理。
- **验收：** 匿名、伪造身份、凭证类型混用、过期/撤销均拒绝；用户与节点身份分离，默认拒绝越权，凭证不进入 URL/日志/命令行。

### [ ] T11 实现节点 WS 认证会话与重连

- **前置：** T05、T10。
- **实现：** 节点主动连接配置的 IP+端口，在 WS 升级握手中提交节点凭证；网关将验证身份绑定 hello/能力/修订、会话代数与实例。
- **交付：** 握手截止、心跳确认/失联、带抖动退避、单实例/重复身份仲裁和节点连接/降级状态，不要求域名或证书。
- **验收：** 错误/过期/撤销凭证、半开/静默丢包、掉线、重复连接、批量重连、旧会话消息；未验证身份头无效，不混淆登记与在线。

### [ ] T12 实现 HTTP 查询、流式路由与取消

- **前置：** T06、T09、T11。
- **实现：** 用户身份/节点权限校验、请求 ID 去重、HTTP NDJSON 与 WS 对应、chunk 序号、唯一 terminal、背压及取消转发。
- **交付：** 一个 host.status 从网关到节点的完整查询；办公用户与节点可共用配置端口，但各路由强制正确凭证类型和绑定身份。
- **验收：** 两个模拟节点路由隔离；BUSY/OFFLINE/超时/断线/慢消费者/用户断开有确定终态或中断，缓冲有界、不自动重放。

### [ ] T13 实现 MCP 并提前验证真实 AI 客户端

- **前置：** T12。
- **实现：** ops-mcp 使用 rmcp stdio，接入用户凭证/HTTP/取消/总超时；先连通节点发现和 host.status，其他工具随核心完成接入。
- **交付：** 无真实秘密的客户端配置、结构化结果和可读摘要，模型侧预算执行前下推，终结元信息保留。
- **验收：** 实际支持 stdio 的 AI 客户端跑通 MCP → HTTP → WS → 节点，记录 HTTP/WS 与认证完整程序资源基线；stdout 无杂文，部分/未知不伪装成功。此项不替代最终独立 Linux 部署验收。

### [ ] T17 完成编码、多行事件与事件时间搜索

- **实现：** plain_lines/timestamped_multiline/json_lines profile，UTF-8/GBK/GB18030/UTF-16 流式解码，line/event 匹配及 UTC [from,to)。
- **交付：** 源字节与展示位置分开，事件/解码缓冲上限、时间未判定/损坏与不完整事件；配置允许时按确定轮转关系拼接事件。
- **验收：** 中文跨块/跨页、BOM/无效编码/有损替换、乱序/时区/时间边界、堆栈/尾部半事件；不拿 mtime 或猜测时间声称查全。

### [ ] T18 完成 gzip/zstd 搜索与压缩上下文

- **前置：** T17。
- **实现：** 顺序流式解压、多 member/frame、窗口/输入/展开/CPU/时间限制；暂停时保留有界解压状态，仅显式续查继续。
- **交付：** 解压后转码前的证据字节域、match_ref 上下文与计费回读、状态过期和损坏错误。
- **验收：** 固定压缩样本与未压缩基线一致，高展开量/损坏/截断/超限/续查过期；不假装随机 seek、不全文解压落盘或驻留内存。

### [ ] T19 完成只读服务与系统日志工具

- **前置：** T14、T17、T18。
- **实现：** services.list/inspect 只读 D-Bus、logs.system 的授权本机 journal/文本后端、boot/时间/服务/级别/关键词查询。
- **交付：** 系统 OOM/段错误/IO/文件系统/服务失败证据，原生 journal 游标、条目/时间/输出预算及实际可用能力。
- **验收：** 受控服务正常/失败/退出、无权/非 systemd/清理日志；不调用 LoadUnit/StartUnit/ResetFailed 等有状态方法。journal 内部 IO 无法准确计量要标注，不能用返回文本量冒充扫描量。

### [ ] T20 完成有界多节点调度与汇总

- **前置：** T13、T16、T19。
- **实现：** queries.run/continue/cancel 固定授权节点集合，派发前分配全局预算，公平调度与所有子请求取消。
- **交付：** 逐节点成功/部分/离线/错误/取消/未调度结果，总覆盖、已知计数下界和多节点续查状态。
- **验收：** 慢/离线节点不阻塞全部返回；多节点不能各花全额预算；未查全不声称全局最新或完整总量，续查不绕过持续读取配额。

### [ ] T21 统一所有工具的授权、脱敏与撤销

- **前置：** T10、T19、T20。
- **实现：** 网关与节点对用户/节点/工具/目录/服务/日志源取交集，统一出站脱敏；权限/预算收紧与配置修订影响队列、在途、游标。
- **交付：** 全工具授权矩阵，原文读取独立权限，强制脱敏目录禁原始字节/Base64。
- **验收：** 每个入口的越权/撤销/配置切换/脱敏失败和边界截断；旧游标不保留旧权限，返回正文、摘要、stderr/审计/HTTP trace 均不泄露秘密。

## 五、真实测试环境、最终回归与交付
